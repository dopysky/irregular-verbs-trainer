Тренажёр неправильных глаголов — версия 37

GitHub Pages: загрузите ВСЕ файлы из архива (включая три icon-*.png) в корень репозитория, заменив старые.

Что исправлено в версии 37:
- после ошибки и «Не знаю» показывается правильный ответ, слово возвращается в очередь;
- интервальные повторения работают: уровень слова растёт, только когда подошёл срок повтора (10 мин -> 1 день -> 3 дня) в тренировке блоков; одна ошибка снижает уровень на 1;
- добавлен экран «Мои ошибки»; счётчик «Сегодня» обнуляется каждый день;
- неоднозначные переводы (say/speak/tell -> «говорить») не дают неверных вариантов; в письменном ответе принимаются все подходящие глаголы;
- название папки сохраняет регистр; при переносе слово нельзя удалить случайно;
- «Закончить тренировку» не вызывает всплывающий экран результатов;
- защита от повреждённых данных в браузере; звук стабильнее на iOS;
- service worker: сначала сеть, потом кэш; запросы к другим сайтам не кэшируются;
- иконки, theme-color, safe-area, фокус с клавиатуры;
- исправлены транскрипции и формулировка «ты слышишь».
