Версия 9: взята за основу v8. Главная содержит только блоки с прогрессом; блоки не разворачиваются. Клик по блоку выбирает его, кнопки запускают тренировку или просмотр слов. Словарь открывает папки по клику без кнопки «Открыть». Добавлены «Мои слова» и папочная система с возможностью добавлять слово в несколько папок. Для GitHub Pages все пути относительные, Service Worker использует отдельный кэш версии 9.
