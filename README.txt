Тренажёр неправильных глаголов — v19

GitHub Pages: загрузить содержимое этой папки в корень репозитория.

В версии v19:
- 151 глагол из исходного набора;
- обновлённый коммерческий, более живой дизайн;
- блоки и прогресс оформлены как учебный дашборд;
- экран изучения блока — таблица V1 / V2 / V3 с компактными транскрипциями;
- словарь получил разнообразные задания на перевод и аудирование без тренировки форм V2/V3 для пользовательских слов;
- неправильные глаголы в словаре тоже тренируются через разные задания, но без отдельного заучивания форм;
- ошибочные ответы в словарной тренировке возвращаются на повтор, а тренировка не заканчивается после первого ответа;
- прогресс словарей отображается отдельно;
- после тренировки показывается понятный итог: закреплено, осталось и изменение прогресса;
- кнопка «Подмешать случайные» из словаря убрана;
- действия «Перенести» и «Удалить» представлены иконками;
- подсказка — ключ, прослушивание — только иконка;
- автоматический звук вынесен в общий переключатель в шапке;
- ручное прослушивание работает даже при выключенном автоматическом звуке;
- добавлены короткие звуки правильного и неправильного ответа;
- текстовые подписи результата там, где достаточно зелёной/красной подсветки, убраны;
- формулировки заданий сделаны разговорными.
