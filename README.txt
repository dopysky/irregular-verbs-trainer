Тренажёр неправильных глаголов — v17

GitHub Pages: загрузить содержимое этой папки в корень репозитория.
В версии v17:
- 151 глагол из исходного набора;
- учебные группы по произношению/моделям звучания, вместо блоков по 15;
- выбранная группа поднимается в большую карточку сверху;
- на маленьких карточках только прогресс;
- слова показываются в одну строку: V1 V2 V3 + перевод;
- автозвук только для открытых английских слов;
- ручная озвучка доступна там, где она не раскрывает ответ;
- словарь «Неправильные глаголы» тренирует перевод RU↔EN, а не формы;
- пользовательские слова получают случайные варианты автоматически;
- «Перенести» открывает нормальное окно выбора папок;
- «Закончить тренировку» возвращает в исходный раздел;
- ошибки тренируются все вместе и разными типами заданий с приоритетом проблемных типов;
- подсказка раскрывает по одной новой букве за нажатие.
