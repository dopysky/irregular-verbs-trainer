Конфиденциальность в KOKORA

KOKORA — тренажёр английского языка. Здесь объясняется, какие данные используются для входа и сохранения занятий.

Какие данные используются

  • Адрес электронной почты и идентификатор аккаунта — для регистрации и входа.
  • При входе через Google сервис получает данные профиля, предоставленные Google, включая адрес почты и идентификатор аккаунта. Пароль Google сайту KOKORA не передаётся.
  • Прогресс упражнений, результаты ответов, личный словарь и настройки — для продолжения занятий на разных устройствах.
  • Данные сессии, настройки и локальная копия прогресса могут сохраняться в браузере устройства для работы сайта.

Где обрабатываются данные

Для аккаунтов и сохранения прогресса используется Supabase. Вход через Google обрабатывается Google. Сайт размещён на GitHub Pages; письма для регистрации и восстановления доступа отправляются через Gmail. Эти сервисы обрабатывают данные, необходимые для их работы, в том числе технические данные соединения.

Хранение и удаление

Данные аккаунта и прогресс сохраняются в сервисе, чтобы ими можно было пользоваться на разных устройствах. Чтобы запросить удаление аккаунта и связанного с ним прогресса или задать вопрос о данных, напишите на alina.capture@gmail.com. Локальные данные сайта также можно удалить в настройках браузера; при этом несинхронизированный прогресс может быть потерян.
